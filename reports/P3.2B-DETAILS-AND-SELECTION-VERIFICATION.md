# P3.2B - Details, selection and seat maps (STEP 4, Gate C)

## 1. Flow

```text
{offerId, offerItemRef [, options]} -> surface policy -> surface sales-scope resolver
   -> GetAncillaryOffersService.FindItemAsync: fetch the flight offer again, shop again in every authorized point of sale, find the item by its ref
        Details:   + published definition (typed specification), the chosen provision, its active pricing  -> AncillaryOfferDetailSnapshot
        Selection: + IAncillaryShoppingEngine.EvaluateSelectionAsync(context, candidate identity, typed selection) -> AncillarySelectionSnapshot
        SeatMaps:  + IFlightSeatMapReference per covered flight -> typed "unavailable"
   -> surface mapper -> surface DTO
```

Nothing is read by a raw id from the request, nothing is written, no stock is held, no document is issued. A detail or a selection of an item that is no longer produced by the engine for this caller is 404 / 16811.

## 2. Canonical detail (`Query/AncillaryOffers/Snapshots/AncillaryOfferDetailSnapshot.cs`)

| Part | Source | Rule |
|---|---|---|
| item | the engine candidate found by ref (price, quantity, availability, readiness, reasons) | the engine's values, not recomputed |
| `Specification` | `AncillaryServiceDefinition.SpecificationArgs()` of the published definition version of the candidate | the nine typed profile sections of Phase 1; exactly one is filled |
| `IncludedAllowance` | baggage facts of the flight offer for the item's traveller and covered flights | `verified` only when the producer stated a unit |
| `BaggageRule` | `provision.BaggageApplication`: free pieces, first / last excess piece, weight + unit, purchase application, charge kind, allowance concept | null when the provision has none |
| `SeatRule` | `provision.SeatApplication`: seat numbers and seat characteristic codes authored on the provision | rules, not seats |
| `Restrictions` | provision passenger types, provision sales window, definition sales dates, permitted and blackout travel periods, advance purchase, purchase stage | only what is authored; empty lists and nulls otherwise |
| `Terms` | provision disposition, reissue / refund policy, form of refund, commissionable, interline settlement; definition confirmation requirement | commission and interline only on Backoffice |
| `PublishedRates` | rates of the active pricing in the target currency, with passenger type and age selectors, base, unit total, and which one the engine applied | "rate tiers if published" |

Not in the detail because no model holds it: cancellation deadlines, waiver codes, bag dimensions beyond the specification, seat rows, remaining stock.

## 4. Seat A07-A09 and seat maps (`P32B_DET_02`)

The detail states the published seat specification (purpose, characteristic codes, applicable cabins, exit-row eligibility, adjacent seat, extra-seat purpose and count, external ticket action) and the provision's seat rule (characteristic codes, seat numbers when authored). It contains no row, column, seat or seat-map member (asserted on the serialized JSON), availability stays `NotChecked` and `guaranteed: false`.

`POST /{surface}/v1/AncillaryOffers/SeatMaps` exists on the three surfaces and answers **503, code 16812, `SEAT_MAP_SOURCE_UNAVAILABLE`** with the answer of the source per covered flight (`B1:F1: SourceUnavailable`). Reason: the only flight seat map in the platform is FlightFlow's Backoffice route `GET Backoffice/v1/Flights/{flightId}/SeatMap`; there is no service-to-service route and no trusted way for an agency caller. The port `IFlightSeatMapReference` is bound to `NotConnectedFlightSeatMapReference`. No seat-map contract was invented; this item is **open** and is the dependency for any seat-number selection to become verifiable. A seat-map request for an item that is not a seat product is 422 / 16801 (`P32B_DET_03`).

## 5. Other profiles (`P32B_DET_03`)

A11 meal, A13 pet in cabin, A15 wheelchair, A23 priority boarding, A24 Wi-Fi: each detail has exactly one filled specification section, the one of its profile (Meal, Pet, AssistedTravel, Priority, Connectivity), identical on the three surfaces. The Api and panel section types are generated from the same member list as the Backoffice Phase 1 specification DTOs (same fields, enum names instead of enum objects), so no profile has an invented field. A10 upgrade and A20 lounge are not applicable or are blocked on the captured route and were not used as positive samples.

## 6. Selection (`P32B_SEL_01`)

| Case | Engine answer | On the surfaces |
|---|---|---|
| A01, quantity 2 | `Accepted`, unit 5,450,000, amount 10,900,000, provision not changed | API `selectedPrice 10900000 / 70`, panel `selectedAmount`, Backoffice `selectedQuantityTotal`; ref unchanged; `canPurchase false`; availability not guaranteed |
| A01, quantity 9 | `Rejected`, issue `Quantity` / `QuantityAboveMaximum`, no amount | issue list, amount null |
| A01, no selection | `Incomplete`, no amount | amount null |
| A01 with a seat number | `Rejected`, `SeatNumber` / `SelectionFieldNotAllowed` | issue list |
| A24 with a ticket fee | unit 981,000, **no** amount (order-level fee unapplied) | `selectedPrice null`, the 100,000 fee under `orderLevelFees` |
| per-kilogram product | rate only, reason `ChargeableWeightNotDetermined` (price report) | no amount |

Only an `Accepted` selection carries an amount (`P32B_ENG_09`; before this task a rejected quantity still carried quantity x rate). `Accepted` means the engine accepted the input; it is not a sale, a hold or a stock check. The same cases were repeated over real HTTP on the Backoffice surface (closure report section 5). `currentOfferItemRef` is the ref of the candidate after evaluation; it differs from the requested ref when the selection moved the traveller to another provision (`offerItemChanged` / `provisionChangedBySelection`).

## 7. Open points of this gate

1. Seat-map source (section 4).
2. Allowance concept for sources that state pieces and weight together (A02).
3. Chargeable weight of per-kilogram products.
4. Terms that the domain does not model (cancellation deadlines, waivers) are absent, not defaulted.
