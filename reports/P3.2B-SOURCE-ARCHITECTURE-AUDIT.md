`AllowedPointOfSaleIds` is read only by fare visibility in search (`Services/OfferSearch/AirfareMatchingService.cs:100`); the price-by-OfferId pipeline does not read it. The commercial section inside an OfferId is not read on any `Price` route; `Service/v1/FlightOffers/Details` re-prices with the section of the id itself (`Services/Service2Service/ServiceFlightOfferDetailService.cs:20`).

### Channel numbers

`AeroTech.Messages.Core.Enums.Channel` differs per repository: AirAvail and AirPrice `IBE = 1, BackOffice = 2, API = 3, GUI = 4`; Ancillary and Ordering `BackOffice = 1, IBE = 2, PartnerAPI = 3, AgencyPanel = 4`. Ancillary therefore carries the named value only (`Channel.BackOffice`, `Channel.PartnerAPI` for AirAvail's `API`) through `PointOfSaleEligibilityQuery.Channel`; no integer is sent or compared. A future eligibility provider must translate by name.

### Point-of-sale set

AirAvail resolves a set (0, 1 or many ids). The engine evaluates one id. The shared service now calls the engine once per id of the set and keeps the results apart (section 4). The eligibility source itself is still not connected: AirPrice exposes its point-of-sale conditions on no service-to-service route (AirAvail reads them by SQL from its own read model). `IPointOfSaleEligibilityReference` stays bound to `NotConnectedPointOfSaleEligibilityReference`.

## 4. Target architecture as built

```text
BackofficeController  (Surface.Backoffice) -> BackofficeSalesScopeResolver --+
OtaController         (Surface.Ota)        -> ApiSalesScopeResolver ---------+--> AncillarySalesScope (owner, channel, point-of-sale set, customer, currency, sales instant)
OtaPanelController    (Surface.OtaPanel)   -> OtaPanelSalesScopeResolver ----+        (Api and OtaPanel share AgencySalesScopeService)
                                                                              |
        IFlightOfferProvider (Application/FlightOffers) <- Providers/Offer/FlightOfferProvider (the only wire knowledge)
                                                                              |
        GetAncillaryOffersService: FlightOffer -> FlightOfferFacts -> one AncillaryShoppingContext per point of sale
                                                                              |
                         IAncillaryShoppingEngine.ShopAsync (unchanged contract, once per point of sale)
                                                                              |
        AncillaryShoppingSnapshot (FlightOffer, scope, facts, per point of sale: context + CanonicalAncillaryOfferResult + items with OfferItemRef)
              |                                   |                                   |
   Backoffice mapper -> Backoffice DTO      Api mapper -> Api DTO           OtaPanel mapper -> OtaPanel DTO
```

| Layer | Path | Content |
|---|---|---|
| Application | `src/AeroTech.Ancillary.Application/FlightOffers/` | `IFlightOfferProvider`, `FlightOffer` records (moved out of the Shopping assembly; `Providers.csproj` now references Application instead of Shopping) |
| Domain ports | `Domain/_Shared/Contracts/IRequestCountry.cs`, `IFlightSeatMapReference.cs` | `X-Country` of the request; seat-map source check |
| Shopping | `src/AeroTech.Ancillary.Shopping` | only context, engine, results, selection, readers. One engine change: section 2 of the price report |
| Shared read layer | `Query/AncillaryOffers/Snapshots/` | `AncillarySalesScope`, `AncillaryShoppingSnapshot`, `AncillaryOfferDetailSnapshot`, `AncillarySelectionSnapshot`, `OfferItemRef`, `AuthorizedPointsOfSale`, `AgencySalesPolicy`, `FlightOfferShoppingContextMapper` |
| Shared services | `Query/AncillaryOffers/Queries/{GetAncillaryOffers, GetAncillaryOfferDetail, EvaluateSelection, GetSeatMap}/` | one service per operation; none references a surface DTO |
| Surfaces | `.../Queries/<operation>/{Backoffice, Api, OtaPanel}/` and `Query/AncillaryOffers/Dto/{Backoffice, Api, OtaPanel}/` | query (inbound contract), handler, mapper, sales-scope resolver, DTOs per surface |
| REST | `RestApi/V1/AncillaryOffers/Controllers/{BackofficeController, OtaController, OtaPanelController}.cs` | four actions each |
| Providers | `Providers/SeatMap/NotConnectedFlightSeatMapReference.cs` | answers "source unavailable" |

No new project, no migration, no aggregate. The old shared DTO types (`AncillaryOffersDto`, `AncillaryOfferDto`, `OfferJourneyDto`) no longer exist as shared types: the files were moved to `Dto/Backoffice` and the two top types renamed `BackofficeAncillaryOffersDto` / `BackofficeAncillaryOfferDto`. Reference audit after the move: `grep` for `AncillaryOffersDto\b`, `AncillaryOfferMapper\b`, `Shopping.FlightOffers` and `FlightOfferSalesScope` over `src` and `tests` finds only the new Backoffice names.
