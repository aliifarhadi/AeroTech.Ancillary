### Q2. Conflict — which variants may have Order coverage
- Pack ch.06 ("PerOrder"): "for every Profile that is inherently traveller-specific, Scope=Order is rejected". Only A22 and A24 are "pax/order if supported".
- S2-01 built a blocklist (Seat and AssistedTravel only), so an Order-scoped A01, A12 or A13 would be offered with no traveller.
- The domain has no coverage-scope rule per variant at all: `AncillaryProvision.cs:211` only checks `Enum.IsDefined`.
- S2-02 forbids Stage 1 changes.

Options:
- (A) The engine allows an Order unit only for A22 and A24; every other variant gets `BeneficiaryRequired`. No Stage 1 change.
- (B) A, plus refuse Order scope at provision Define/Change. This changes Stage 1 and needs your explicit permission (CLAUDE rule 5 says the aggregate guards its invariants at authoring).

**Recommendation:** A now, and B as a separate Stage 1 correction when you order it.

### Q3. Conflict — A02 weight package has no option source
- Pack ch.07 §7.6: "A02 PackageProductRef … package=5kg/10kg really independent options".
- v12.1 decision D08, still in the domain: "fixed weight packs are separate definitions". Each A02 definition is one package (`BaggageSpecification.PackageWeightKg`).
- No `PackageProductRef` exists in the domain, AirAvail or ReferenceData. S2-02's acceptance asks for "two real source packages (fixture from authoritative contract)", and no such contract exists.

Options:
- (A) One choice derived from the definition itself: value = `serviceDefinitionRef`, label = package weight, `sourceState=Known`. The engine rejects any other `PackageProductRef`. Two packages = two definitions = two offer items.
- (B) `sourceState=Unknown`, zero choices. Because `PackageProductRef` is required, every A02 sale stays NeedsVerification until a package catalog exists.

**Recommendation:** A. It follows the D08 model and invents nothing.
Answer:

### Q6. Response shape of the Details additions (CLAUDE rule 6)
Proposal, identical member names on Backoffice, Api and OtaPanel Details (Api inside `data`):
