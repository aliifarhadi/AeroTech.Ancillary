## 3. Decisions taken by the agent (for the audit)

- Specifications are EF owned types in their own tables (one row per definition), sets are owned rows with a composite key.
- The selection contract is derived from variant + specification and is not stored.
- External quote authority = provider key of the Active External supplier of the definition; no quote is fetched.
- Allowed pricing units, date bases and application type are fixed per variant in `AncillaryVariant`. A03 also allows PerKilogram.
- Pet acceptance is enforced as booking `SubjectToConfirmation`; a pet rule must keep it.
- Invented closed values where the pack names none: `AssistanceCommunicationMethod` (Verbal, Written, SignLanguage, Braille), `MedicalEquipmentKind` (Oxygen, Stretcher, MedicalAssistance for AOXY/STCR/MEDA), disability SSR list BLND/DEAF/DPNA, wheelchair list WCHR/WCHS/WCHC.
- A11 and A15 can never be Paid. A12 may be Free on a provision (for example a cabin that includes the meal) - a first draft refused it and was relaxed because an existing family test files exactly that.
- The baggage charge kind lives in the specification; a provision rule may repeat it but not contradict it (16321). The v12.1 refusal 16317 is no longer raised.
- Profile and variant are immutable once a version of the reference was published (16217).
- Products outside the nine profiles (insurance, eSIM, hotel, transfers, per-room, per-vehicle units, CheckIn/CoverageStart/Activation date bases) can no longer be authored.
- **Data:** on the Owner's instruction of 2026-10-09 ("test data, delete it") the migrations are the plain scaffold, without backfill. The dev database rows of schemas `Ancillary` and `ReadModel` were deleted (they were already 0 rows) and both migrations applied. Rows of an older database would receive `PriceOrigin = 0` / `ConsumptionUnit = 0`; this was not handled.
